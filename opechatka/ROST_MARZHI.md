# Что добавить для роста маржи — О! печатка

Критерии отбора:
1. **Минимальные вложения** (желательно до 15–40 тыс. ₽ или на текущем оборудовании)
2. **Быстрая продажа** — клиент покупает сразу / заказ готов в день обращения (не «неделя на производство»)
3. **Высокая маржа** — расходники дешёвые относительно цены
4. **Ложится на текущий поток** — фото, копии, печати, подарки в ЖК

---

## Топ-рекомендации (внедрять в первую очередь)

### 1. Фотомагниты — ★★★★★
| | |
|---|---|
| Цена клиенту | 150–350 ₽ / шт |
| Себестоимость | 20–60 ₽ |
| Маржа | **70–85%** |
| Срок | 5–15 минут |
| Вложения | Магниты-заготовки + клей/ламин или сублимация — **3–10 тыс. ₽** |

**Почему зайдёт:** логичный апселл к печати фото. «Распечатать 20 фото + 2 магнита бабушке».  
**Как продавать:** витрина у кассы + оффер «к печати от 10 фото — магнит со скидкой».

---

### 2. Готовые фоторамки 10×15 / 15×20 / 20×30 — ★★★★★
| | |
|---|---|
| Цена | 250–900 ₽ |
| Себестоимость | 80–350 ₽ |
| Маржа | **50–65%** |
| Срок | Мгновенно |
| Вложения | Партия 30–50 шт — **8–25 тыс. ₽** |

**Почему:** в отзывах уже хвалят подбор рамок — значит спрос есть. Не ждать багет 7–12 дней.  
**Как продавать:** рядом с выдачей фотопечати, 3–4 ходовых размера.

---

### 3. Канцтовары «у кассы» (файлы, папки, скоросшиватели, конверты) — ★★★★★
| | |
|---|---|
| Наценка | **×2–3** к закупу |
| Срок | Мгновенно |
| Вложения | **5–15 тыс. ₽** |

**Почему:** клиент пришёл за копией договора → уходит с папкой и файлами. Нулевая технология.  
Ассортимент: файлы А4, папка-скоросшиватель, конверт А4/А5, файловая папка на молнии, бейдж-холдер.

Пакет: «дизайн + печать + ламин + клипса» = 350–500 ₽.

### 7. Экспресс-пакеты из уже существующих услуг — ★★★★★ (вложения ≈ 0)
Самый быстрый рост маржи **без закупа**.

| Пакет | Состав | Цена пакета | Зачем |
|---|---|---|---|
| «Паспорт плюс» | Фото 4 шт + 2 ламината + файл | 550–650 ₽ | Чек +150–250 ₽ |
| «ИП за час» | Печать + штемпельная подушка + 10 визиток-пробников | +300–500 ₽ к печати | Апселл |
| «Подарок за 30 мин» | 10 фото 10×15 + магнит + рамка | 800–1200 ₽ | Вместо «просто печать» |
| «Документы под ключ» | Скан 10 стр + запись на флешку + 2 файла | 350–500 ₽ | Удобство |

Маржа высокая, потому что цена пакета выше суммы «по меню», а время то же.

## Чего лучше не добавлять сейчас

| Идея | Почему нет |
|---|---|
| Своя полноцветная сублимация «с нуля» (если нет пресса) | Дорогое оборудование |
| 3D-печать | Долго, другой бизнес |
| Большой склад сувениров | Замораживает деньги |
| Сложный интернет-магазин | Долгая окупаемость |
| Ещё один широкоформатник | Капекс, не маржа |

## План внедрения на 2 недели (минимум денег)

**Неделя 1 (бюджет ~15–25 тыс. ₽)**
1. Собрать 4 экспресс-пакета и повесить ценник у кассы / в Telegram.
2. Закупить файлы, папки, 2 размера рамок, заготовки магнитов.
3. Запустить бейджи на текущем ламинаторе.

**Неделя 2**
4. Добавить стикер-бумагу и 2 шаблона календаря.
5. Подушки для печатей + 10–15 флешек.
6. Скрипт продавца: «К печати фото добавить магнит/рамку?»

**Ожидаемый эффект:** +10–20% к среднему чеку без роста трафика → при обороте 600 тыс. это примерно **+60–120 тыс. ₽ выручки/мес**, из них большая часть с высокой маржой (**+40–80 тыс. ₽ к валовой прибыли** при нормальной конверсии апселлов).

---

## Что сказать клиенту у кассы (короткие скрипты)

- После фотопечати: «Сделать магнит или сразу вставить в рамку?»
- После фото на паспорт: «Заламинировать и положить в файл — 150 ₽, не помнётся.»
- После печати для ИП: «Подушку для штемпеля сразу взять? Обычно через месяц заканчивается.»
- Семейные фото: «Можем за 15 минут настольный календарь — подарок готов сегодня.»
