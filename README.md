# Анимация сборки лестницы

Автономная интерактивная 3D-демонстрация сборки лестницы на центральном
монокосоуре. Последовательно показаны монтаж балки, кронштейнов, деревянных
ступеней и болтового крепежа.

Для просмотра откройте `index.html` в современном браузере. Визуализация не
требует сборки или внешних зависимостей.
